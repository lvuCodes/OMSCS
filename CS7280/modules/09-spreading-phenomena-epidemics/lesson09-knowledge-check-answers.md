**Q1** (purpose of the "Exposed" state in SEIR): To represent individuals who are infected but not contagious

**Q2** (rate of change of the infection percentage): $\frac{di(t)}{dt} = \bar{k} \beta i(t)(1-i(t)) - \mu i(t)$

**Q3** (endemic infected fraction under SIS with homogeneous mixing): $1 - \frac{\mu}{\bar{k} \beta}$

**Q4** (two major factors $R_0$ depends on):
1. True — The average attack rate of the pathogen
2. False — The primary transmission method
3. True — The average number of contacts each infected individual has
4. False — The average amount of time an individual remains infectious

**Q5** (true about superspreading events): SSEs can be caused by individuals with a very large number of contacts

**Q6** (attributes NOT captured by the degree block approximation):
1. True — Network assortativity
2. True — Network community structure
3. False — The degree distribution is a power-law
4. False — The degree distribution is a truncated power-law
