[Video](https://cdnapisec.kaltura.com/p/2019031/sp/201903100/embedIframeJs/uiconf_id/43123921/partner_id/2019031?iframeembed=true&playerId=kaltura_player&entry_id=1_l80gi12m)

[[lessons/14-p4l2-black-box-testing/transcripts-md/23-category-partition-demo-transcript|transcript]]

<u>**WARNING**</u>: In the file `4.spec.const.error.single` of the demo, the pattern of having a single marker followed by a property constraint is error-prone, because the TSLgenerator will prioritize the single marker, and ignore the property definition. This is problematic if there are other choices depending on the property. For example, the line `[single] [property emptyfile]` will not define the property `emptyfile`.

This will [trigger an error with the TSLCompiler](https://github.com/divark/TSLCompiler/blob/main/docs/USER_MANUAL.md#common-errors-3). A fixed version of this file can be found [here](https://github.com/divark/TSLCompiler/blob/main/examples/grep/4.spec.const.single).

The latest version of the TSLCompiler can be found [here](https://github.com/divark/TSLCompiler/releases/latest/).
