Imagine that you have collected the following set of five requirements for an ATM system but only have resources to satisfy two, possibly three of those.

Suitably prioritize the requirements by marking them as Mandatory, Nice to have, or Superfluous.

## Question 1

The system shall check the PIN of the ATM card before allowing the customer to perform an operation.

- [ ] (M) Mandatory
- [ ] (N) Nice to have
- [ ] (S) Superfluous

## Question 2

- [ ] (M) Mandatory
- [ ] (N) Nice to have
- [ ] (S) Superfluous

## Question 3

The system shall allow customer to withdraw cash using an ATM card.

- [ ] (M) Mandatory
- [ ] (N) Nice to have
- [ ] (S) Superfluous

## Question 4

The system shall allow customer to deposit money using an ATM card.

- [ ] (M) Mandatory
- [ ] (N) Nice to have
- [ ] (S) Superfluous

## Question 5

The system shall allow customer to change the PIN of an ATM card.

- [ ] (M) Mandatory
