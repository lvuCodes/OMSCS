## Overview

This graduate-level introductory course in information security teaches the basic concepts and principles of information security and the fundamental approaches to securing computers and networks. The curriculum encompasses security fundamentals, risk management, software and operating-system security, database security, cryptography, network authentication, malware analysis, web and mobile security, and legal and ethical considerations.
