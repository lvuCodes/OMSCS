# CS 6035 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6035-introduction-information-security](https://omscs.gatech.edu/cs-6035-introduction-information-security)).

These are **in addition** to Georgia Tech's base hardware requirements:

- Processing: minimum 4 × 2 GHz virtual cores (more recommended)
- Memory: minimum 8 GB RAM for the VM (host needs significantly more)
- Storage: ~100 GB free disk (SSD or HDD)
- High-speed internet (VM downloads, updates, submissions)
- **Supported:** Intel/AMD PCs (Windows, Linux) and Intel-based Macs
- **Not supported:** Apple ARM-based Macs (M1/M2/M3+), Chromebooks, systems below minimums

- **VirtualBox only** — provided VMs are built with VirtualBox; other virtualization software (VMware, Parallels, etc.) is not supported or tested
- Reference: [Required Reading](https://github.gatech.edu/pages/cs6035-tools/cs6035-tools.github.io/RequiredReading/)
