## Overview

Deep learning is a sub-field of machine learning that focuses on learning complex, hierarchical feature representations from raw data. The course covers fundamental principles, mathematics, and implementation details including optimization methods, neural-network modules, and common architectures. Students learn convolutional and recurrent neural networks and applications in computer vision, NLP, and reinforcement learning through PyTorch programming assignments and a capstone project.
