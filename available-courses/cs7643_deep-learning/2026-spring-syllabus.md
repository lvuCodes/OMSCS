## Course Overview

Deep learning is a sub-field of machine learning focused on learning complex, hierarchical feature representations from raw data. The course covers fundamental principles, mathematics, and implementation details — optimization methods (gradient descent, backpropagation), neural-network modules, and common architectures. Through PyTorch programming assignments, students implement these building blocks and apply them in a capstone project to real-world scenarios in computer vision, natural language processing, and reinforcement learning.

## Prerequisites

A strong mathematical foundation (linear algebra, calculus including partial derivatives, probability and statistics); prior machine-learning coursework (e.g., CS 7641 equivalent) — this should not be a first ML course; and strong Python programming skills. A CUDA-compatible GPU is recommended but not required.
