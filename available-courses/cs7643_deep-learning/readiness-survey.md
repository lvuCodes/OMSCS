# CS 7643 — Readiness / Suggested Background

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-7643-deep-learning](https://omscs.gatech.edu/cs-7643-deep-learning)).

- Strong mathematical foundation: linear algebra, calculus (partial derivatives), probability and statistics
- Prior machine-learning coursework required (e.g., CS 7641 equivalent) — not a first ML course
- Strong Python programming skills
- CUDA-compatible GPU recommended but not required
