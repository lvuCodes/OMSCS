# CS 6300 — Readiness / Suggested Background

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6300-software-development-process](https://omscs.gatech.edu/cs-6300-software-development-process)).

Students should have familiarity with Java and basic software engineering concepts, and should have taken an undergraduate software engineering course or have some experience in industry.

Before enrolling, students should be able to affirm the following:

1. Prior software engineering coursework, or experience working as a software engineer in industry.
2. Understanding of requirements, software design, and software testing.
3. Familiarity with the Java language (or a similar object-oriented language such as C++ or C#).
4. Comfort with learning new technologies and working with software tools.
5. Ability to participate in regular remote team meetings.
