# CS 6300 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6300-software-development-process](https://omscs.gatech.edu/cs-6300-software-development-process)).

- Browser: current version of Chrome or Firefox (Internet Explorer 9+ supported).
- Operating system: Windows XP or later, Mac OS X 10.6 or later, or a recent Linux distribution.
- Internet: 2+ Mbps recommended (0.768 Mbps minimum download speed).
- Ability to install the Eclipse IDE and other free software.
- Google Hangouts for office hours.
