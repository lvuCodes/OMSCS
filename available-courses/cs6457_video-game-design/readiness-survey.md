# CS 6457 — Readiness / Suggested Background

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6457-video-game-design](https://omscs.gatech.edu/cs-6457-video-game-design)).

- C# programming experience (required)
- Familiarity with a strongly typed object-oriented language (e.g., Java) is helpful
- Suggested: linear algebra and computer graphics basics — affine transformations, quaternions, 3D projection, scene graphs, and Phong reflection models
