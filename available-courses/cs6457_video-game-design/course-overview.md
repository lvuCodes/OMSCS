## Overview

The course covers many game design topics including game engine concepts and technologies, structural elements of games, and the game design process. This project-based course includes individual assignments and group work, with learning objectives centered on creating 3D games with real-time control that achieve "Game Feel" qualities like those found in Super Mario 64.
