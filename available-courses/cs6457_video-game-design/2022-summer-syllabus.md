# CS 6457 — Summer 2022 Syllabus

Source: `downloads/CS 6457 2022-2.pdf` (OMSCS sample syllabus, Summer 2022; cross-listed as CS 4455/CS 6457). Instructor: Jeff Wilson, PhD.

## Description

The course covers many game design topics including game engine concepts and technologies, structural elements of games, and the game design process. CS 6457 is a project-based course with both individual assignments and a group project. Learning objectives focus on creating fully three-dimensional games with real-time game-object control, including games that meet the criteria of "Game Feel" such as Super Mario 64.

## Technical Requirements

All software development uses the Unity Engine and the C# programming language. Students need a Windows PC or Mac capable of running Unity.

## Suggested Background Knowledge

Students are not expected to know Unity. Beyond C# experience, familiarity with a strongly typed object-oriented language such as Java is helpful. Useful prerequisite knowledge includes linear algebra and computer graphics basics — affine transformations of homogeneous coordinates, transformation order, quaternions, 3D projection, matrix stacks, scene graphs, and lighting models such as the Phong reflection model.

## Grading

| Weight | Component |
|---|---|
| 10% | Quizzes (short quiz per learning module) |
| 45% | Individual Milestones (Warmup 1%, Character Control/Animation 11%, Environment Interaction/Physics 11%, UI and Prefabs 11%, AI 11%) |
| 45% | Team Project (Pitch & Interaction Demo 4%, Alpha Demo 8%, Playtesting & Analysis 8%, Final Game 25%) |

Assignments and weighting may change each semester (see Canvas). Failure to participate in the team project can result in loss of all team-project credit for an individual.
