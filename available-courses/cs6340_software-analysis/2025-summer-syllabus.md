## Course Overview

The course explores software analysis — determining whether software is correct and finding bugs ahead of users. It covers how development environments detect issues (e.g., unused variables) before compilation and how strongly typed languages prevent bugs. With software testing, debugging, and security assessment now taking more resources than development itself, the industry increasingly relies on tools to write better software. The course investigates multiple analysis techniques and their limits, with most lectures accompanied by hands-on labs. Techniques include dataflow analysis, constraint-based analysis, type systems, automated test-case generation, and symbolic execution. Labs evaluate practical use; exams evaluate understanding of lessons not covered by labs; quizzes evaluate all lessons including theory.

## Course Objectives

After completing the course, students will be able to:

- Evaluate the suitability of different analysis and testing techniques for different programs and constraints
- Implement and run analyses to determine useful facts about a program
- Apply testing techniques to find bugs
- Describe qualitative properties of different analysis/testing techniques
- Compute the outcome of a given analysis or testing technique on a program

## Prerequisites

Fluency in a C-family language (C, C++, Java, or C#); most classwork uses C++. Familiarity with basic CS and mathematics concepts and UNIX-like environment tooling.
