# CS 6340 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6340-software-analysis](https://omscs.gatech.edu/cs-6340-software-analysis)).

Meet or exceed Georgia Tech's [minimum hardware requirements](https://sco.gatech.edu/hardware-requirements/) for incoming undergraduates:

- Processor: 64-bit multi-core (quad-core or higher recommended); the course itself notes at least an x64 processor
- Memory: 16 GB (more recommended); the course notes at least 8 GB RAM for a usable VM experience
- Primary storage: 256 GB SSD (more recommended)
- Networking: dual-band (2.4/5 GHz) 802.11ac wireless
- I/O: physical keyboard and mouse/trackpad

- Docker (preferred; required for Apple M-series processors) or a course-provided VirtualBox VM — labs are only supported in the container/VM, not directly on host hardware
- Chrome browser, relatively current version (required for Honorlock exam proctoring)
