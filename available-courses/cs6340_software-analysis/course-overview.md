## Overview

This course explores the field of software analysis — techniques for determining software correctness and finding bugs ahead of users. Topics include dataflow analysis, constraint-based analysis, type systems, automated test-case generation, and symbolic execution. The course examines how development environments detect issues (such as unused variables) before compilation and how strongly typed languages prevent bugs.

CS 6340 is a foundational course counting toward the OMSCS degree requirements.
