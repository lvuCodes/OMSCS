# CS 7295 — Spring 2026 Syllabus

Source: `downloads/CS 7295 2026-1.pdf` (OMSCS sample syllabus, Spring 2026; titled "CS7295: GPU HW/SW"). Delivery: 100% web-based, asynchronous. Instructor: Hyesoon Kim. The Fall 2025 syllabus (offered as CS 8803 O21) is identical apart from term dates and is not separately retained.

## Course Overview

The course explores the software and hardware aspects of GPU development. Through hands-on projects, students gain basic CUDA programming skills, learn optimization techniques, and develop an understanding of GPU architecture. It also covers compiler principles for GPU-related software issues and research papers on hardware challenges.

## Prerequisites

C/C++ and Python programming and Linux command-prompt experience are necessary; prior CUDA experience is not required. Basic computer organization (instruction sets, pipelining) is expected. Recommended (not required): CS 6200 for large C++ projects, CS 6290 for architecture simulators, CSE 6220 for CUDA-heavy projects, and CS 6340 for program analysis.
