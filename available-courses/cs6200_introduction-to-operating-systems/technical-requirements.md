# CS 6200 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6200-introduction-operating-systems](https://omscs.gatech.edu/cs-6200-introduction-operating-systems)).

**Browser and connection:** A current version of Chrome, Firefox, or Edge; 2+ Mbps recommended (0.768 Mbps minimum).

**Operating system (64-bit required):**

- Windows XP or higher with updates
- OS X 10.6+ with updates (M-series Macs may experience issues with ptrace and AddressSanitizer tools)
- Recent Linux distributions

**Virtual machine:** A provided VM identical to the submission testing environment; download details are posted in Piazza.
