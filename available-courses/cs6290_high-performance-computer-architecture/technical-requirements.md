# CS 6290 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6290-high-performance-computer-architecture](https://omscs.gatech.edu/cs-6290-high-performance-computer-architecture)).

- 32 GB available disk space; ability to install free software
- Oracle VirtualBox with a Linux virtual machine for projects
- Browser: current Chrome or Firefox (IE 9+ supported)
- Connection: 2+ Mbps recommended (0.768 Mbps minimum)
- OS: Windows XP+ or Mac OS X 10.6+
