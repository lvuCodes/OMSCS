# Available Courses

Course descriptions and syllabi for the OMSCS courses offered in Fall 2026, copied from the official OMSCS course pages and course sites.

## Structure

```
available-courses/
├── current-courses.md        OMSCS course listing with program markers and links
├── browse-classes.md         Fall 2026 Banner course catalog with an OMSCS-acceptance column
├── prereqs.md                Prerequisites and recommended background per course
└── <code>_<course-name>/
    ├── course-overview.md
    ├── <YYYY>-<term>-syllabus.md   One file per offering term
    ├── readiness-survey.md
    ├── technical-requirements.md
    └── img/
```
