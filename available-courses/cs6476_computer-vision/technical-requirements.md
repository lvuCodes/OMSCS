# CS 6476 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6476-computer-vision](https://omscs.gatech.edu/cs-6476-computer-vision)).

- Minimum 32 GB available disk space
- Oracle VirtualBox VM with a Linux setup (required for projects)
- Up-to-date Chrome or Firefox; 2+ Mbps recommended (0.768 Mbps minimum)
- Windows XP+, OS X 10.6+, or a recent Linux distribution
