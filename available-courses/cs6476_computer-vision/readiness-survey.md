# CS 6476 — Readiness / Suggested Background

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6476-computer-vision](https://omscs.gatech.edu/cs-6476-computer-vision)).

- Working knowledge of Python for mathematical programming
- Linear algebra, vector calculus, and probability
- Basic image-processing concepts helpful but not required

Self-assessment covers Gaussian distributions, computing image derivatives, drawing lines without libraries, grayscale conversion, and debugging algorithms on real images.
