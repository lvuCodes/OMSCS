## Overview

The course introduces the principles and practice of regression analysis, covering linear regression, generalized linear models, and model-selection techniques. Students engage in hands-on data-science work with emphasis on active participation, independent exploration, and developing the ability to apply appropriate methods to real data — from exploratory data analysis through model building, diagnostics, and result communication, in both R and Python.
