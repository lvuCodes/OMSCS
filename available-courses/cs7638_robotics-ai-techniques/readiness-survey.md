# CS 7638 — Readiness / Suggested Background

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-7638-robotics-ai-techniques](https://omscs.gatech.edu/cs-7638-robotics-ai-techniques)).

- Working knowledge of Python (data types, functions, OOP, loops, conditionals, exception handling)
- Strong undergraduate-level probability and linear algebra
- Command-line navigation
- Recommended: machine learning, computer vision, or robotics coursework
