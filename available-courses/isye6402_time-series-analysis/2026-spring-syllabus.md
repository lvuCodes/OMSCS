# ISYE 6402 — Spring 2026 Syllabus

Source: `downloads/ISYE 6402 2026-1.pdf` (OMSCS sample syllabus, Spring 2026). Instructor: Nicoleta Serban. Models implemented in R; an accompanying GitHub repository includes data examples.

## Course Overview

Students explore standard time series modeling techniques including regression analysis, univariate ARMA/ARIMA modeling, (G)ARCH modeling, and Vector Autoregressive (VAR) models with forecasting, identification, and diagnostics. The final module covers modern machine-learning forecasting systems such as Meta's Prophet, LinkedIn's Silverkite, and Uber's Orbit, plus a brief introduction to deep-learning approaches. The course emphasizes individual discovery and counts as a free elective.

## Prerequisites

Undergraduate or graduate statistics/probability, basic programming proficiency, linear algebra, calculus, and linear-regression modeling experience. R statistical software is used throughout.
