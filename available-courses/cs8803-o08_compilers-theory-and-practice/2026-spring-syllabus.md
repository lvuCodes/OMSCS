## Course Overview

The course teaches the theory and practice behind building automatic translators (compilers) for higher-level programming languages, engineering compiler phases in Java or C++:

- **Front End:** scanners, parsers, semantic analysis
- **Middle End:** intermediate forms, syntax-directed translation, runtime organization
- **Back End:** instruction selection, register allocation, code generation, code optimizations

## Prerequisites

Strong data structures and algorithms knowledge, solid programming ability in Java or C++, capacity to build substantial software projects, and Linux environment proficiency.
