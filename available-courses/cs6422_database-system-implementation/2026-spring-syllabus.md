# CS 6422 — Spring 2026 Syllabus

Source: `downloads/CS 6422 2026-1.pdf` (OMSCS sample syllabus, Spring 2026). Instructor: Joy Arulraj.

## Course Overview

A hands-on dive into designing and implementing relational database management systems. Students learn the internals of a database system — storage management, indexing, and query execution — and build a fully functional database in C++ through programming assignments addressing real-world challenges.

## Prerequisites

Data structures/algorithms (CS 1332) and computer systems/networks (CS 2200) required; OS (CS 3210) and introductory databases (CS 4400) recommended. C++ proficiency is essential, along with a strong foundation in systems programming and software engineering.
