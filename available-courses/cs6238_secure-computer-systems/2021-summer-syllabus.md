# CS 6238 — Summer 2021 Syllabus

Source: `downloads/CS 6238 2021-2.pdf` (OMSCS sample syllabus, Summer 2021, Section O01/OCY). Delivery: 100% web-based, asynchronous, via Canvas. Instructor: Mustaque Ahamad.

Retained as the summer-term variant; the compressed summer schedule changes the grading weights relative to the [Spring 2023 syllabus](2023-spring-syllabus.md) (the course description and learning outcomes are otherwise the same — see that file).

## Grading (Summer Variant)

| Weight | Component |
|---|---|
| 30% | Quizzes (13; lowest dropped) |
| 20% | Programming Projects (best two of Projects I–III, plus Project IV) |
| 25% | Midterm Exam |
| 25% | Final Exam |

Projects: I — Memory Protection, II — Authentication, III — Access Control, IV — Distributed Systems Security. Grade scale is curve-based (≥ 0.5 SD above mean ≈ A), identical to the spring offering. Consult the source PDF for completion rules, due dates, and policies.
