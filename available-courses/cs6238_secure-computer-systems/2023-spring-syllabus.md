## Description

Applications and services are supported by software platforms such as operating systems and databases. Secure execution of such applications depends on the trust assumptions that can be made about these systems. By providing the right mechanisms for protecting sensitive information and other resources, operating systems and databases can facilitate the development of secure applications. The course takes a uniform approach to exploring security support in operating systems and databases, addressing problems such as authentication and access control traditionally handled at the system level, along with in-depth coverage of distributed-systems security.

## Course Goals and Learning Outcomes

- Demonstrate the need for a trusted computing base (TCB) and how it protects resources in a computer system
- Analyze how hardware-supported memory protection enables isolation of the TCB and of untrusted programs
- Develop, implement, and evaluate authentication and access control in computer systems
- Understand and evaluate security in distributed systems
- Apply security concepts to protect data stored in database systems
- Be familiar with recent research related to the topics covered

## Grading

| Weight | Component |
|---|---|
| 20% | Quizzes (13 weekly; lowest 3 dropped) |
| 20% | Programming Projects (best two of Projects I–III, each 5%) |
| 10% | Project IV — Distributed Systems Security (required) |
| 30% | Midterm Exam |
| 30% | Final Exam |

Projects: I — Memory Protection, II — Authentication, III — Access Control, IV — Distributed Systems Security. Exams are closed book/notes, free-response in Canvas, one attempt, 2-hour limit, available for one week.

**Grade scale:** Curve-based — an overall score ≥ 0.5 standard deviation above the class average typically earns an A; well below average earns a C (> 1 SD below); > 2 SD below may be assigned an F.
