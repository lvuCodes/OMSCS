# CS 6238 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6238-secure-computer-systems](https://omscs.gatech.edu/cs-6238-secure-computer-systems)).

- High-speed internet connection
- Laptop/desktop with a minimum 2 GHz processor and 4 GB RAM
- Windows or macOS
- Microsoft Office Suite and Adobe PDF software
- Virtualization software (VirtualBox) for creating virtual machines
- Development tools for compiling and debugging
