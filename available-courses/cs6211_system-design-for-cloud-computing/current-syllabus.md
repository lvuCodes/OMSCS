## Course Overview

Four hands-on, project-intensive immersive modules giving in-depth experience developing different layers of a cloud computing infrastructure: software-defined networks (SDN), system software, network function virtualization (NFV), and application development. Each module includes 4–5 hours of lectures, graded online quizzes, and supervised lab components using technologies such as OpenFlow, Mininet, and Azure Cloud.

## Prerequisites

CS 4210/6210 and/or instructor consent for equivalent coursework.

## Required Materials

All materials via Canvas: video lectures for all four modules, workshop and project instructions, per-lecture assessment quizzes, slides and references, and Microsoft Azure credits for student projects.

## Grading

Letter grade is A or F only:

- 100% completion of auto-graded post-lecture quizzes (unlimited attempts)
- Complete all weekly workshops and capstone projects with an "Accept" stamp

No exams. Continuous assessment through quizzes and hands-on work. Audit requirements: attend 70% of synchronous sessions, watch all mandatory pre-recorded lessons, submit weekly quizzes on time (no workshop/project submission required).

## Course Schedule
