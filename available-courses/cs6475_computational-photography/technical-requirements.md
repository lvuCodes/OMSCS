# CS 6475 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6475-computational-photography](https://omscs.gatech.edu/cs-6475-computational-photography)).

- Internet connectivity
- A camera with aperture/shutter speed/ISO control
- Windows 8+, macOS 10.15+, or a recent Linux distribution
- Anaconda; Python and OpenCV bindings
