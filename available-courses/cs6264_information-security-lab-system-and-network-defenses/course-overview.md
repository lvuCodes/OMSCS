## Overview

A hands-on cybersecurity lab course developing in-depth knowledge and practical skills across seven areas: software security (vulnerabilities, CFI/ASLR/DEP, program analysis), malware analysis (environments, threat intelligence, behavioral analysis), endpoint security (system-call hooking, VM introspection, forensics), network security (protocol vulnerabilities, TLS, intrusion detection, alert correlation), web security (browser security models, access control, WebView vulnerabilities), mobile security (iOS/Android models, malware, privacy leaks, rooting), and machine learning for security (classifiers, evasion attacks, robustness).
