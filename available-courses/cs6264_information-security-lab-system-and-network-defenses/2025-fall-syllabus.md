# CS 6264 — Fall 2025 Syllabus

Source: `downloads/CS 6264 2025-3.pdf` (OMSCS sample syllabus, Fall 2025; titled "Information Security Lab: System and Network Defenses"). The Summer 2025 sample syllabus PDF is byte-identical and is not separately retained. Instructor: Wenke Lee.

## Course Description

The course develops in-depth knowledge and hands-on skills across important cybersecurity areas — software security, malware analysis, endpoint security, network security, web security, mobile security, and machine-learning-based security analytics. Hands-on labs, prototypes, and comprehensive projects reinforce each area:

1. **Software Security** — vulnerabilities, protection mechanisms (CFI, ASLR, DEP), and program analysis; projects extend analysis tools to find exploitable bugs and generate triggering input.
2. **Malware Analysis** — analysis environments, threat intelligence, behavioral analysis; projects extend a malware-analysis system to examine a new malware family.
3. **Endpoint Security** — system-call hooking, VM introspection, forensic analysis, record-and-replay; projects use record-and-replay to find an attack's root cause.
4. **Network Security** — protocol vulnerabilities, TLS, intrusion detection, alert correlation; projects extend an open-source IDS to detect stealthy attacks.
5. **Web Security** — browser security models, access control, WebView vulnerabilities; projects implement a phishing attack via iframes/popups in WebView.
6. **Mobile Security** — iOS/Android models, malware, privacy leaks, rooting attacks.
7. **Machine Learning for Security** — classifiers, evasion attacks, robustness; projects generate evasion attacks and harden a model.

## Prerequisites

An introductory information-security course (small overlap with CS 6035) is expected, and ideally a network-security course (small overlap with CS 6262). Prior programming experience in C, Java, or a similar language is required.
