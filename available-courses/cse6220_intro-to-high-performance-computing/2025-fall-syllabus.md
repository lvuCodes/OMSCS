## Course Description

An introduction to high-performance computing: developing, analyzing, and implementing parallel and locality-efficient algorithms and data structures. The course addresses three machine models — (1) sequential/parallel machines with memory hierarchies (external-memory models), (2) multicore/manycore shared-memory machines (work-span models), and (3) distributed-memory machines (network models) — applied to sorting, graph/tree searching, and linear algebra using Cilk Plus, OpenMP, MPI, and similar frameworks.

## Prerequisites

Comfort designing and analyzing basic sequential algorithms and data structures with big-O notation (CS 3510 level); C/C++ proficiency; command-line Unix/Linux experience; familiarity with calculus, linear algebra, and probability.

## Required Materials

Ananth Grama et al., *Introduction to Parallel Computing* (Addison-Wesley, 2003) — freely available electronically to GT students via the GT Library and/or VPN.
