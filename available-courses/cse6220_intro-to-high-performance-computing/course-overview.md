## Overview

A graduate-level introduction to scalable parallel algorithms, emphasizing efficiency across problem and system sizes. The course teaches algorithmic techniques for multicore, distributed-memory, and memory-hierarchical systems, exploring fundamental problems like sorting and linear algebra while implementing algorithms on real parallel systems using OpenMP and MPI.
