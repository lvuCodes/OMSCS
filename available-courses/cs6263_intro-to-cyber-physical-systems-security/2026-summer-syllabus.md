## Course Overview

Foundational security concepts applied to cyber-physical systems, with emphasis on Industrial Control Systems (ICS). Students engage with both offensive tools used by attackers and defensive technologies, developing practical skills in securing critical infrastructure.

## Prerequisites & Required Background

- A computer networking class
- An information security class
- Programming experience with Python

## Required Textbooks

- *Industrial Network Security*, 2nd ed. — Eric D. Knapp, Joel Thomas Langill (ISBN 978-0124201149)
- *Applied Cyber Security and the Smart Grid* — Eric D. Knapp, Raj Samani (ISBN 978-1597499989)
- Optional: *Hacking Exposed Industrial Control Systems* — Bodungen et al. (ISBN 978-1259589713)

Both required texts are available digitally through the GT library.
