# CS 6310 — Readiness / Suggested Background

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6310-software-architecture-and-design](https://omscs.gatech.edu/cs-6310-software-architecture-and-design)).

Students should have completed an undergraduate software-engineering course, CS 6300, or have significant industrial development experience. Java competence and object-oriented programming knowledge are required. Helpful to confirm familiarity with:

- Software engineering fundamentals (requirements, design, testing)
- Object-oriented programming, preferably Java
- Comfort learning new technologies and tools
- Ability to work with remote team meetings
