# CS 6310 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6310-software-architecture-and-design](https://omscs.gatech.edu/cs-6310-software-architecture-and-design)).

- A virtual container is provided for local setup
- Screen/voice capture software for demos
- Browser: current Chrome or Firefox (IE 9+ supported)
- Connection: 2+ Mbps recommended (0.768 Mbps minimum)
- OS: Windows XP+, OS X 10.6+, or a recent Linux distribution
