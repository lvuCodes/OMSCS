# CS 6310 — Summer 2026 Syllabus

Source: `downloads/CS 6310 2026-2.pdf` (OMSCS sample syllabus, Summer 2026). Sections O01, OSZ — online attendance, lectures via asynchronous video.

## Course Description

Principles and concepts involved in the design and analysis of large software systems.

## Learning Outcomes

1. Express the analysis and design of an application using UML
2. Specify and evaluate software architectures
3. Select and use appropriate architectural styles
4. Understand and apply object-oriented design techniques
5. Select and use appropriate software design patterns
6. Understand and perform a design review
7. (Time permitting) Specify functional semantics of an application using OCL

## Course Materials

All materials are provided through Canvas, Ed Discussions, Georgia Tech GitHub, and online access to the Georgia Tech Library.

## Prerequisites

- A grade of D or higher in CS 6300, Software Development Process
- Solid proficiency in writing computer programs
- Basic experience developing in Java using sequence, selection, and iteration control structures, and reading/writing external files (or ability to learn Java well enough based on other languages)
- A basic understanding of some similarly well-defined design process and/or language

## Grading

| Weight | Component |
|---|---|
| 40% | Projects (15% Initial Analysis & Design, 25% Iterative Design & Implementation) |
| 20% | Exams (#1 mandatory; #2 optional — if taken, score is the average of #1 & #2; includes potential peer-review bonus) |
| 10% | Assignment Quizzes (7 quizzes: #1/Honor Code + best 5 of 6 from #2–#7) |
| 5% | Practice Quizzes (29 quizzes, one per lesson, best 24 of 29) |
| 5% | Peer Feedback Surveys |
| 15% | Team Participation (based on Peer Feedback Surveys, evaluated by the instructor) |
| 5% | Ed Discussion Participation |

**Grade scale:** [100:90] = A, (90:80] = B, (80:70] = C, (70:60] = D, (60:0] = F. Scores are not auto-rounded; no extra points or assignments.
