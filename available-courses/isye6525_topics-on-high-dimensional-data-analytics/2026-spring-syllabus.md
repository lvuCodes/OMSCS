# ISYE 6525 — Spring 2026 Syllabus

Source: `downloads/ISYE 6525 2026-1.pdf` (OMSCS sample syllabus, Spring 2026). Instructor: Kamran Paynabar.

## Course Overview

The course focuses on analysis of high-dimensional structured data — profiles, images, and other functional data — using statistical machine learning. Topics include functional data analysis, image processing, multilinear algebra, tensor analysis, and regularization techniques, along with optimization methods used in statistical modeling and machine learning and their computational aspects. The course is a free elective and does not count toward specializations.

## Prerequisites

Knowledge of regression and linear algebra, plus basic programming in Python, R, or Matlab.
