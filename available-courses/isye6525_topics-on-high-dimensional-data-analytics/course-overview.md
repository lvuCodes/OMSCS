## Overview

The course focuses on analysis of high-dimensional structured data including profiles, images, and other types of functional data using statistical machine learning. Topics include functional data analysis, image processing, multilinear algebra, tensor analysis, and regularization techniques, along with optimization methods used in statistical modeling and machine learning and their computational aspects. The course is a free elective and does not count toward specializations.
