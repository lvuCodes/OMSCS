# CS 6250 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6250-computer-networks](https://omscs.gatech.edu/cs-6250-computer-networks)).

- Browser: current Chrome or Firefox required (IE 9+ supported)
- Connection: 2+ Mbps recommended (0.768 Mbps minimum)
- OS: Windows XP+, OS X 10.6+, or a recent Linux distribution
