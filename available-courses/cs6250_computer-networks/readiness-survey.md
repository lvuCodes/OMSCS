# CS 6250 — Readiness / Suggested Background

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6250-computer-networks](https://omscs.gatech.edu/cs-6250-computer-networks)).

A prior networking course is not a prerequisite, but this is an advanced course — introductory material is covered only at a review level. Students should already understand basic networking concepts (IP addresses, subnets, TCP vs. UDP, the OSI model and encapsulation, three-way handshakes, basic HTTP, client-server vs. peer-to-peer) and be able to program in Python at an intermediate level. Familiarity with network programming and using virtual machines is helpful.
