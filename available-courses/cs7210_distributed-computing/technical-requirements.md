# CS 7210 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-7210-distributed-computing](https://omscs.gatech.edu/cs-7210-distributed-computing)).

- High-speed internet connection
- Computer with a minimum 2 GHz processor and 2 GB RAM
- Windows or macOS
- Microsoft Office Suite (or comparable) and Adobe PDF reader
- Firefox, Chrome, and/or Safari (Chrome required for HonorLock)
