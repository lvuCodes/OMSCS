# CS 7641 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-7641-machine-learning](https://omscs.gatech.edu/cs-7641-machine-learning)).

- **Browser:** current Chrome or Firefox strongly recommended (Internet Explorer 9+ supported).
- **Connection:** 2+ Mbps recommended (0.768 Mbps minimum).
- **Operating system:** Windows XP or higher with latest updates; Mac OS X 10.6 or higher with latest updates; or a recent Linux distribution with supported browsers.
