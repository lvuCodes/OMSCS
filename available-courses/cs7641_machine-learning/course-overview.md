## Overview

This graduate-level Machine Learning series was originally created by Charles Isbell (now Chancellor at the University of Illinois Urbana-Champaign) and Michael Littman (Associate Provost at Brown University), featuring Socratic discussion lectures. Theodore LaGrow leads the current offering with updated examples, tools, and assessments.

The course progresses from supervised learning (prediction with labeled data) through unsupervised learning (discovering structure in unlabeled data) to reinforcement learning (sequential decision-making); each unit's outputs inform subsequent modules. Lectures are delivered via Canvas; reports are written in LaTeX on Overleaf; code lives in private Georgia Tech GitHub repositories; communication is through Canvas announcements and Ed Discussions; weekly supplemental recordings cover advanced topics. Students develop a portfolio of defensible analyses, models, and policies — including four major reports (~30 pages total) across supervised learning, optimization/uncertainty, unsupervised learning, and reinforcement learning — with judgment about when and why to apply each method.

**Target audience.** Graduate students and working professionals seeking principled, hands-on mastery of modern ML. Students should be comfortable with Python, linear algebra, probability, and basic calculus.
