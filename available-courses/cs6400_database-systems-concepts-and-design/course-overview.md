## Overview

This course is built around learning-by-example and learning-by-doing: it applies a database application development methodology to a major real-world project, introducing the database concepts, techniques, and tools needed to build a database application from scratch as they are needed. Topics include the Extended Entity-Relationship model, the Relational model, relational algebra and calculus, SQL, normalization, efficiency, indexing, and metadata management.

CS 6400 is a foundational course counting toward the OMSCS degree requirements.
