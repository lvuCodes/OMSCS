## Required Text

Elmasri & Navathe, *Fundamentals of Database Systems*, 7th edition (Pearson, 2016). Any edition listed as the 7th edition is acceptable; prior editions are not supported.

## Overview

Built on learning-by-example and learning-by-doing: the course applies a database application development methodology to a major real-world project, introducing concepts, techniques, and tools as needed, while learners apply the same methodology to their own team project. Topics include the Extended Entity-Relationship Model, the Relational Model, relational algebra/calculus and SQL, normalization, efficiency and indexing, and metadata management and archival. This is a graduate-level introduction; advanced topics (query optimizers, NoSQL, DBMS implementation) are not covered.

## Prerequisites

Familiarity with at least one scripting/programming language (PHP, Python, Java); some software-engineering and Git/source-control familiarity is helpful; willingness to learn basic system/database administration; readiness to work remotely with team members.

## Learning Outcomes

- Understand and apply data independence, database and DBMS architecture, and the placement of a DBMS in the application stack
- Apply the theoretical foundation of relational databases and query languages to create SQL definitions and queries meeting requirements
- Create a relational database application (requirement analysis, specification, design, implementation)
- Evaluate alternative internal schema structures and create indices for efficient operation
