# CS 6210 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6210-advanced-operating-systems](https://omscs.gatech.edu/cs-6210-advanced-operating-systems)).

- VT-X or AMD-V capable machine (Intel i3/i5/i7+ or AMD Athlon 64 X2/FX+)
- 8 GB RAM minimum
- Apple M1/M2 is currently not supported
- 2+ Mbps internet recommended

- Chrome browser (required for Honorlock proctoring)
- OS: Windows 10+, OS X 10.9+, or a recent Linux distribution
- Microsoft Teams for office hours
