## Overview

The course introduces a selection of key cutting-edge technologies in Internet computing systems, covering eight broad categories: cloud computing and data centers; Internet server technologies (multi-tier application servers, Content Distribution Networks, key-value stores); peer-to-peer computing; crowd computing; Internet search (crawl, indexing, ranking, retrieval); blockchain and digital cryptocurrency (Bitcoin, Ethereum); mobile and edge computing; and big data systems and intelligent Internet services. It teaches design principles, techniques, and system optimizations without requiring prior knowledge of these topics.
