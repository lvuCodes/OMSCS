# CS 6262 — Readiness / Suggested Background

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6262-network-security](https://omscs.gatech.edu/cs-6262-network-security)).

It is recommended that students have taken CS 6035: Introduction to Information Security, or an equivalent class. Recommended technical background includes basic web development (JavaScript/HTML/CSS, browser DevTools), XSS and Same-Origin Policy concepts, basic Python scripting, network-protocol basics, and familiarity (or willingness to learn) with Wireshark and Snort.
