# CS 6262: Network Security

Source: [omscs.gatech.edu/cs-6262-network-security](https://omscs.gatech.edu/cs-6262-network-security)

## Instructional Team

- **Wenke Lee** — Creator, Instructor
- **Melissa Chen** — Head TA

## Overview

A graduate-level course in network security covering an introduction and review of networking and security basics, plus advanced topics: DDoS attacks, malware analysis, penetration testing, Internet protocol security (IP, TCP, DNS, BGP), web security, network monitoring, blockchain/cryptocurrencies, cloud security, and attack-tolerant systems.
