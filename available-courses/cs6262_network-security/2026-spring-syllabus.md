# CS 6262 — Spring 2026 Syllabus

Source: `downloads/CS 6262 2026-1.pdf` (OMSCS sample syllabus, Spring 2026). Delivery: 100% web-based, synchronous, via Canvas. Instructor: Dr. Wenke Lee.

## Learning Objectives

A graduate-level course in network security teaching the concepts, principles, and techniques to secure networks. Main topics:

1. Large-scale attacks and impacts — DDoS attacks, malware-based underground economy
2. Penetration testing and security measures — basic techniques/tools, social engineering, human factors
3. Security of Internet protocols — TCP/IP vulnerabilities, BGP security, DNS cache poisoning and DNSSEC
4. Advanced web security — browser security models, session management, HTTPS goals and pitfalls
5. Advanced malware analysis — obfuscation, mobile malware
6. Advanced network monitoring — botnet detection systems
7. Internet-scale threat analysis — mapping the Internet, domain/network reputation
8. Bitcoin and cryptocurrencies — blockchain basics, emerging technologies
9. Big data and security — ML for security analytics, data poisoning and model evasion
10. Cloud security — VM security, property-preserving encryption, oblivious RAM
11. Attack-tolerant systems — secret-sharing, Byzantine fault tolerance, diversification, moving-target defense

## Prerequisites

Familiarity with basic information-security concepts is expected (minimal overlap with CS 6035). Recommended background: basic web development (JavaScript/DOM, HTML forms and frames, CSS, browser DevTools); XSS concepts (reflected/DOM-based/stored XSS, Same-Origin Policy, `postMessage`); basic Python scripting; some disassembly familiarity; network-protocol basics and awareness of attack traffic (DDoS, brute-forcing, botnet C&C, web attacks); and prior or willing-to-learn experience with Wireshark and Snort. Students from a weaker programming background are strongly advised to take CS 6035 first.
