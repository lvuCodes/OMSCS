## Overview

This course introduces broad classes of techniques and tools for analyzing and visualizing data at scale, emphasizing how to complement computation and visualization to perform effective analysis. Students learn visual and computational methods, gain breadth across data types, work with real datasets, and complete hands-on programming assignments. The course culminates in small-team projects exploring novel interactive data and visual analytics approaches.
