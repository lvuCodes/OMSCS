# CS 8803 O27 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-8803-o27-computer-graphics-ai-era](https://omscs.gatech.edu/cs-8803-o27-computer-graphics-ai-era)).

- Laptop with a graphics card (integrated GPU sufficient; discrete GPU recommended)
- Support for GPU compute and graphics APIs (GLSL or WebGL for shader assignments)
- Google Colab access for lightweight neural-network training; Python and Git familiarity recommended
