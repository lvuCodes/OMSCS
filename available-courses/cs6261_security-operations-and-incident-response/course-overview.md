## Overview

The course provides the background information and skill sets necessary to participate in and lead a cyber security incident response effort. It is not foundational and does not count toward specializations, but qualifies as a free elective. Students learn foundational incident-response tools and methods, how to identify malicious IT behavior, and containment/eradication/response techniques for emerging threats.
