# CS 6261 — Spring 2025 Syllabus

Source: `downloads/CS 6261 2025-1.pdf` (OMSCS sample syllabus, Spring 2025; cross-listed as CS 6261/PUBP 8803). Delivery: 100% web-based on Canvas. Instructors: Jimmy Lummis, Christopher Craig, Kyle Koza. The Fall 2024 sample syllabus is near-identical and is not separately retained.

## Course Overview

The course provides the background information and skill sets necessary to participate in and lead a cyber security incident response effort. It is not foundational and does not count toward specializations, but qualifies as a free elective.

## Course Goals

Understand foundational tools for successful incident response programs; understand and apply modern incident response methods; identify malicious IT behavior; apply containment, eradication, and response methods to emerging threats; and evaluate incident performance to improve future processes.

## Prerequisites

Familiarity with system logs and log-analysis tools (e.g., Splunk); understanding of how computer systems and networks function.
