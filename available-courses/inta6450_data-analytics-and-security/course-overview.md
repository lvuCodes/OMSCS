# INTA 6450: Data Analytics and Security

Source: [omscs.gatech.edu/inta-6450-data-analytics-and-security](https://omscs.gatech.edu/inta-6450-data-analytics-and-security)

- **Jeff Borowitz** — Instructor
- **Emma Shumway** — Head TA

## Overview

The course examines big data foundations and analytics, covering computing technology and statistical principles. It focuses on the nature of underlying technical challenges and statistical assumptions in applied fields such as fraud detection and communication monitoring. The course includes discussions of ethical implications and a data-analytics project using real datasets to identify patterns and vulnerabilities.
