# CS 7650 — Fall 2025 Syllabus

Source: `downloads/CS 7650 2025-3.pdf` (OMSCS sample syllabus, Fall 2025). Instructor: Mark Riedl. Programming assignments in Python using Jupyter notebooks (Google Colab or local), submitted to Gradescope.

## Course Overview

The course gives an overview of modern data-driven techniques for natural language processing, moving from shallow bag-of-words models to richer structural representations of how words interact to create meaning, including language models. It covers machine-learning techniques relevant to NLP and progresses through increasingly sophisticated approaches to computational linguistics.

## Prerequisites

A data structures course and an introductory artificial intelligence or machine learning course. Python proficiency; a Google Colab Pro account is recommended but not strictly required.
