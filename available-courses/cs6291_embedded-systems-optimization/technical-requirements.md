# CS 6291 — Technical Requirements

Source: [course-overview.md](course-overview.md) → "Before Taking This Class" (from [https://omscs.gatech.edu/cs-6291-embedded-systems-optimization](https://omscs.gatech.edu/cs-6291-embedded-systems-optimization)).

- Chrome or Firefox (current version); 2+ Mbps internet
- Windows 7+ or macOS 10.10.5+; dual-core 2.4 GHz CPU; 2 GB free space minimum
- Webcam (800×600+) and working microphone
- Vagrant and VirtualBox for the development environment
