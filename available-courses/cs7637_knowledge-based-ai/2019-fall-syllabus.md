# CS 7637 — Fall 2019 Syllabus

Source: [Fall 2019 syllabus and schedule](https://lucylabs.gatech.edu/kbai/fall-2019/). Converted from the public course website (most recent public sample syllabus).

## Course Overview

Knowledge-Based AI covering semantic networks, case-based reasoning, planning, analogical reasoning, and related cognitive-AI topics across 26 lessons.

## Required Materials

Udacity course platform (ud409), Canvas (LMS), Proctortrack for exams, JDF format for written submissions.

## Grading

| Component | Weight |
|---|---|
| Homework (3 assignments) | 30% |
| Projects (3 projects) | 45% |
| Exams (3 proctored) | 15% |
| Class Participation | 10% |

Scale: A (90+), B (80–90), C (70–80), D (60–70), F (<60).

## Late Policy

No late work accepted; emergency exceptions via the Dean of Students.
